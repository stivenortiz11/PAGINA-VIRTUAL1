# PAGINA-VIRTUAL1

Repositorio de Stiven David Ortiz Calderón · Ingeniería de Sistemas, Universidad ECCI.

## Contenido

- **Raíz (`index.html`)** — Presentación interactiva de la **Actividad No. 3** de Gestión del Talento Humano (caso Bancolombia): plan de retención, evaluación de productividad y modelo de talento humano.
- **`ciudadania-digital/`** — Micrositio anterior sobre apropiación / ciudadanía digital.

## Ver la presentación

Abre `index.html` en el navegador o visita la versión publicada en GitHub Pages:
`https://stivenortiz11.github.io/PAGINA-VIRTUAL1/`

### Navegación
- Flechas del teclado ← → o los botones laterales
- Puntos de navegación y botón "☰ Menú" en la parte inferior
- Rueda del mouse y deslizar en móvil
- Tecla `F` para pantalla completa

## Archivos de la presentación
- `index.html` — estructura y contenido de las diapositivas
- `styles.css` — diseño (estilo oscuro tipo catálogo, animaciones)
- `script.js` — navegación e interactividad
