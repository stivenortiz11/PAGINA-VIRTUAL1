# Actividad No. 3 — Presentación interactiva (Bancolombia)

Presentación interactiva en HTML, CSS y JavaScript para la Actividad No. 3 de Gestión del Talento Humano (Universidad ECCI).

**Autor:** Stiven David Ortiz Calderón · Ingeniería de Sistemas
**Caso:** Bancolombia · Perfil: Desarrollador de Software

## Contenido
- Plan de retención de personal (5 frentes)
- Plan de evaluación de productividad
- Modelo de talento humano (ciclo del empleado)

## Cómo verla
Abre `index.html` en el navegador, o visita la versión publicada en GitHub Pages.

## Navegación
- Flechas del teclado ← →, o los botones a los lados
- Menú clicable en la segunda diapositiva (botón "☰ Menú")
- Rueda del mouse y deslizar en móvil
- Tecla `F` para pantalla completa

## Archivos
- `index.html` — estructura y contenido de las diapositivas
- `styles.css` — diseño (estilo oscuro tipo catálogo)
- `script.js` — navegación e interactividad
